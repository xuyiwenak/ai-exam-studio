# 考点 · 本地模拟考试

一个在自己电脑上运行的模拟考试网页。支持导入 Excel、Word、PDF 题库，预览并修正 AI 识别结果，然后进行限时练习和逐题复盘。

## 启动

macOS 可双击 `start.command`。它会启动本机后台服务，关闭启动窗口后仍可继续考试，下次登录也会自动启动。需要停止时双击 `stop.command`。

也可在项目目录手动运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

浏览器打开 `http://127.0.0.1:8765`。本地服务仅监听 `127.0.0.1`。只有手动运行 `server.py` 时，关闭终端才会停止服务。首次安装 Python 依赖需要联网。

公开仓库内置一套 5 题的演示题库。首页或题库管理中可选择题库，自设题量、考试时间和及格线。考试支持答题卡、标记、自动保存、交卷复盘；进度与最近 30 次成绩保存在当前浏览器。随机考试只抽有完整答案的客观题；“全部”会展示当前题库的所有题。所有规则和及格线均为自测设置。

## 导入题库

1. 在 **AI 配置** 填写兼容 OpenAI Chat Completions 的 API 基础地址、模型 ID 和 API Key。远程地址必须使用 HTTPS；本机模型接口可使用 HTTP。
2. 在 **导入题库** 选择 `.xlsx`、`.docx` 或 `.pdf` 文件（单个最大 20 MB），点击 **用 AI 分析题目**。
3. 预览并修改题目、选项和答案，再保存为本机题库。

Excel、Word 和 PDF 的可提取文字先在本机读取。PDF 中没有足够可提取文字的页面会在本机转成 PNG 图片，直接发送给所配置的多模态模型识别；单次最多处理 40 个图片页。**扫描版 PDF 需要支持图片输入的模型。**文字和图片请求可能产生模型调用费用。测试连接仅检查文字请求，不验证图片能力。

API Key 保存在 `.local/ai-config.json`，文件权限仅允许当前用户读取；导入的题库保存在 `.local/banks/`。上传的原始文件不会被服务长期保存，但提取的文字和扫描页图片会发送给所配置的接口。模型可能识别错误或遗漏答案，请在保存前核对。

## 本地题库与公开代码

公开仓库只包含代码和演示题，不包含个人题库、原始文档或 API Key。`.local/` 和 `source/` 已被 Git 忽略。

若在本机保留了旧版的 `source/VibeCoding.xlsx` 与 `source/OPC题库.xlsx`，可运行 `.venv/bin/python build_question_data.py`，生成私有的 `.local/questions.js`。服务会优先读取此文件，让原有两套题库继续可用；公开的 `questions.js` 则提供演示数据。其他题库可直接通过网页导入。
